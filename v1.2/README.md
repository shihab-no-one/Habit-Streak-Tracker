# Habit Streak Tracker — Version 1.2

Welcome to **Habit Streak Tracker v1.2**. This release updates the core application with flexible tracking options, retroactive history edits, custom notifications, and an updated Nordic Sky UI palette.

---

## ✨ What's New in v1.2

### 📅 Enhanced Calendar & Tracking
* **Interactive 30-Day Grid & Weekly Views:** Visualize completion patterns across multi-day horizons.
* **Past History Editing:** Mark off or correct missed check-ins for prior dates directly from the calendar.

### 🎨 Design & UI Overhaul
* **Nordic Sky Theme Palette:** Clean, high-contrast aesthetic designed for low glare and high focus.
* **Dynamic Light & Dark Modes:** Seamlessly toggles between light surface cards and low-light slate backgrounds.
* **Motivation Screen:** App launch landing screen featuring an interactive, randomized motivational quote engine.

### ⚙️ Granular Habit Controls
* **Pause States:** Freeze habits while taking a break without resetting active streaks.
* **Per-Habit Custom Reminders:** Schedule specific notification times for individual habits.
* **Notification Snooze:** Temporarily defer check-in alerts directly from push notifications.
