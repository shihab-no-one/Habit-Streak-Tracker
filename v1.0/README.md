# Daily Streak Tracker

A minimal, intuitive Android application designed to help users build habits and track daily streaks seamlessly.

---

## Features

* **Streak Tracking**: Easily log daily achievements and view ongoing streak counters.
* **Progress Visualization**: Track historical activity and stay motivated with habit consistency.
* **Lightweight & Fast**: Built with modern Android development standards for high performance.

---

## Tech Stack

* **Language**: Kotlin
* **UI Framework**: Jetpack Compose / Material Design 3
* **Build System**: Gradle (Kotlin DSL)
* **Architecture**: MVVM (Model-View-ViewModel)

---

## Getting Started

### Prerequisites
* **Android Studio**: Ladybug or newer recommended
* **JDK**: Version 17 or higher
* **Android SDK**: API Level 24+ (Android 7.0)
